# Teslo API
Este proyecto es de carácter educativo, del curso de angular de Fernando Herrera: https://www.udemy.com/course/angular-fernando-herrera. 
En este caso corresponde a la parte backend, no desarrollada en el propio curso, pero necesaria para el front que si se desarrollón en la Sección 18: TesloShop Aplicación administrativa ( https://github.com/mjriveraknowmad/curso-angular-tesloshop-front-fh )

1. Clonar proyecto
2. `yarn install`
3. Clonar el archivo `.env.template` y renombrarlo a `.env`
4. Cambiar las variables de entorno
5. Levantar la base de datos

```
docker-compose up -d
```

6. Levantar:

```
npm run start:dev
yarn start:dev

```

7. Ejecutar SEED

```
http://localhost:3000/api/seed
```
